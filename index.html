            Run it locally
            TempleOS compiles HolyC at the command line. All guest code runs at ring 0 in a shared address space.
            The harness handles VM resets, input, screenshots, and grading.
            Requires uv, QEMU, and a provider API key. See the repository for setup and provider options.
            Source and setup instructions
            
      
            git clone https://github.com/jmurzaku/temple-cua
cd temple-cua
uv sync
uv run temple-cua fetch-iso
uv run temple-cua prepare --output assets/baseline.qcow2

uv run temple-cua run --provider cua \
  --model openai/gpt-6.1-sol \
  --baseline assets/baseline.qcow2 \
  --task cursor_callback --output runs/cursor-callback
